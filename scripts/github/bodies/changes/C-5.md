## Change

With location enabled, choosing a **different city** and opening the map should show **that city**, not the area where the player is.

## Scope

- Shared `mapCenter(city, coords)`: centre on the player only when they are in the selected city (`nearestCity`), otherwise on the city centre; Romania's centre when there is neither
- Web map: centre from `mapCenter`; a new city moves the map
- Mobile map: initial region from `mapCenter`; choosing another city while the map is open animates to it

## Acceptance criteria

- [ ] Player in Cluj browsing București: the map opens on București with every București pin in view (browser test)
- [ ] Unit tests for each case of `mapCenter`
