## Change

Remove the **"Open now"** filter; keep **"Available now"**.

## Why

The two differ in one case only: a venue that is open with every pitch booked. "Available now" already means _open and with a pitch free for the next two hours_, so it is what a player who wants to play needs. "Open now" added results the player cannot book, plus a second toggle to understand. The **"Open" badge** on cards stays: it answers a different question (can I call or drop by).

## Scope

- Shared: `openNow` removed from `DiscoverFilters` and `CompanyListQuerySchema` (an old `openNow=true` in a link is ignored)
- API, web URL state, web sidebar and mobile filters sheet: toggle removed; "Available now" gets a one-line explanation
- Tests: the API test now checks that `openNow` changes nothing

## Acceptance criteria

- [ ] No "Open now" control on web or mobile
- [ ] "Available now" explains itself
