## Change

A pitch has **one hourly rate**, the same at every time of day. No peak or off-peak pricing.

## Scope

- Schema: `Pitch.hourlyRate` replaces `offPeakRate`, `peakRate` and `peakHoursDefinition`; existing pitches keep their off-peak rate
- Shared: `CreatePitchSchema` / `UpdatePitchSchema`, `PitchSummary`, `PitchDetail` use `hourlyRate`; `PeakHoursSchema` and `formatPeakHours` removed
- API: Discover price filter, "from" price and sort use `hourlyRate`
- Web and mobile: pricing card shows one "Any time" rate; the pitch page and its Book Now panel show the exact rate, not "from"
- Seed and tests updated; HANDOVER explains how to upgrade an existing dev database
- Open tickets with peak pricing (E05-03, E05-07, E10-03, E10-08, E11-10, mobile E04) get a comment pointing here

## Acceptance criteria

- [ ] `GET /pitches/:id` returns `hourlyRate` and none of the old fields
- [ ] No "peak" wording on any page
