## Change

Shirts never cost money. When booking, the player says whether they want shirts; the booking then gets **one set per team except one** (2 teams → 1 set, 3 teams → 2 sets). The team without a set plays in its own kit.

## Scope

- Schema: drop `Pitch.shirtRentalPrice` and `Booking.shirtRateSnapshot`; add `Booking.shirtSets`. `ShirtInventory.quantity` counts sets.
- Shared: `shirtSetsFor(teamCount, wantsShirts)`; `CreateBookingSchema` gets `wantsShirts` (default false) and loses per-team shirt quantities; `formatShirtColours()`
- API: `GET /pitches/:id` no longer returns `shirtRentalPrice`
- Web and mobile pitch pages: "Free shirts in blue, red and yellow. Ask for them when you book: one set for every team but one."
- Seed: inventories in sets
- Open tickets that price shirts (E05, E06, E10, E11) get a comment pointing here

## Acceptance criteria

- [ ] No price for shirts anywhere in the API, web or mobile
- [ ] `shirtSetsFor` unit-tested for 2 and 3 teams, with and without shirts
