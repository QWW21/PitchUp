## Summary

API tests for phone verification (`POST /auth/verify-phone`, and `POST /auth/resend-code` with `channel: PHONE`), the one E02 endpoint the auth suite did not cover.

## Scope

- Wrong code counts down `attemptsRemaining`; the right code sets `phoneVerified`; a used code is refused
- Codes are scoped by channel: an emailed code cannot verify the phone, nor a texted one the email
- Expired code → 410; the third wrong guess burns the code (429), even for the right code after
- Unknown address → a plain wrong-code answer with no count (no enumeration); malformed code → validation error
- Resending an SMS answers the same for any address
