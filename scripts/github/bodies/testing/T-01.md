## Summary

Set up the test tooling for the monorepo so every later testing task has somewhere to live.

## Scope

- **Vitest** for unit tests in `packages/shared` and `apps/web` (with the `@/` alias and a stub for `server-only`).
- **Playwright** in `apps/web/e2e` for API tests and browser E2E, starting a production build against a dedicated **test database** (`pitchup_test`), pushed and seeded before each run.
- **Jest + React Native Testing Library** in `apps/mobile`.
- Root scripts: `pnpm test` (unit), `pnpm test:e2e` (API + browser), `pnpm test:mobile`, `pnpm test:all`.
- `docs/TESTING.md`: what each layer covers, how to run it, how screenshots are produced.

## Acceptance criteria

- [ ] `pnpm test`, `pnpm test:e2e`, `pnpm test:mobile` each run green on a fresh clone with Postgres available
- [ ] E2E never touches the development database
- [ ] Screenshots from E2E runs land in a predictable folder; `EVIDENCE=1` writes the committed set to `docs/test-evidence/web/`
