## Summary

Jest + React Native Testing Library tests for the mobile app's logic and components — no device needed.

## Scope

- `discoverStore`: hydrate from AsyncStorage, setCity persists, unknown stored city ignored, `effectiveSort`
- `authStore.checkSession`: tokens + `/me` ok → authenticated; `/me` fails → tokens cleared
- `apiClient`: a 401 triggers one shared refresh; refresh failure emits unauthorised
- Components render with fixture data: `CompanyCard` (open badge, "Not rated yet", no distance), `FilterChip`, `RatingBreakdown`, `ReviewCard` (anonymous, manager reply, rating-only), `AmenitiesGrid`, `PricingCard`, `BookNowFooter` disabled states
- `useLocation` mapping of permission results (granted / denied / blocked) with mocked native modules

## Acceptance criteria

- [ ] `pnpm test:mobile` green; native modules mocked in one setup file
