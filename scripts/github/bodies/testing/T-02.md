## Summary

Unit tests for `packages/shared` — the rules both apps rely on.

## Scope

- `schedule.ts`: venue clock, `venueTimeToUtc` across DST changes, `normalizeWeek`, `isOpenAt` (normal, overnight, round-the-clock, closed, malformed), `openIntervalsOn`, `todayStatus`, `formatDayHours`, `addDays` / `dayOfWeek`
- `geo.ts`: `haversineKm`, `nearestCity` (suburb snapping, far away → null), `foldForSearch`
- `format.ts`: `playerDisplayName`, `formatPeakHours`, `formatPitchSize`
- `discover-query.ts`: `companyListQueryString` (repeated keys, amenity expansion, encoding), `hasActiveFilters`, `priceBound`
- `trustTier` boundaries
- Zod schemas: `CompanyListQuerySchema`, auth schemas (password policy, age ≥ 16, name messages)

## Acceptance criteria

- [ ] Every exported function above has tests for its normal and edge cases
- [ ] Runs in under 10 seconds, no database or network
