## Summary

API tests for the auth endpoints, run by Playwright against a real server and test database.

## Scope

- Register (player and manager): validation errors, existing email answers 201 without revealing it, rate limiting charged after validation
- Verify email: wrong code, attempts, right code; resend code
- Mobile login: one error for wrong password / unknown email / unverified account; token pair on success
- Refresh: rotation, reuse of an old refresh token revokes the family
- `/me`: Bearer token (#177), web cookie, bad token, no auth
- Forgot / reset password: same answer for any email, reset with a valid token, used token rejected, old password rejected, web session ended (#176)
- Logout revokes the refresh token
