## Summary

GitHub Actions pipeline running every test layer on each push to `main` and on pull requests.

## Scope

- Jobs: lint + typecheck; unit (Vitest); mobile (Jest); E2E (Postgres service, production build, Playwright Chromium)
- Playwright HTML report and screenshots uploaded as artifacts
- No secrets needed: test-only `NEXTAUTH_SECRET`, local Postgres service

## Acceptance criteria

- [ ] Workflow green on `main`
- [ ] A failing test fails the run and its screenshots are downloadable
