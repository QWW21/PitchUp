## Summary

Unit tests for web logic that does not need a server or database.

## Scope

- `lib/discover/url-state.ts`: reading and writing Discover URL state, dropping malformed values
- `lib/venues/ratings.ts`: `publicRating`, `companyRating` (mean of pitch means, 3-review threshold)
- `LoginForm`'s `safeCallbackPath` (open-redirect guard) — extracted so it can be tested
- `RegisterForm`'s phone normalisation (`toE164`) — extracted so it can be tested
- `lib/auth/tokens.ts`: access-token sign/verify round trip, rejects tampered or wrong-audience tokens, `bearerFromHeader`
