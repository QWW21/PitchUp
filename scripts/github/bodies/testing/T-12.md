## Summary

Bring the E01 acceptance checks into the test suite and CI. `scripts/verify-e01.sh` only ran by hand on macOS (Homebrew paths, the dev database, `pkill`, `python3`), so its checks are ported rather than wrapped.

## Scope

- Unit (`apps/web/src/lib/infra.test.ts`): environment validation (valid accepted; missing/malformed `DATABASE_URL`, short/empty `NEXTAUTH_SECRET`, bad Stripe prefix, non-E.164 Twilio number rejected), the Prisma singleton, Cloudinary signing (sha1 scheme, secret never returned, folder guard, refuses when unconfigured)
- Unit (`packages/shared/src/rules.test.ts`): what `scripts/verify-shared.ts` checked: PRD constants, trust tiers, booking/review/pitch schema rules, login schema, date-of-birth edges
- API (`e2e/api/infra.spec.ts`): no schema drift, one table per model and every enum, idempotent seed, admin bcrypt cost 12, `/health` envelope, rate limiter 429, admin web session → `/me`, no server secret in `.next/static`

## Acceptance criteria

- [ ] Every check in `verify-e01.sh` and `verify-shared.ts` has a test, or is already covered by CI (typecheck) or by `.gitignore` (`.env` never committed)
- [ ] Both scripts removed; README, HANDOVER and ARCHITECTURE updated
