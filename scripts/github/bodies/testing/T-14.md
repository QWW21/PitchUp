## Summary

Jest + React Native Testing Library tests for the E02 mobile auth screens, rendered with a fake navigator and a mocked `authApi`. No device needed.

## Scope

- Onboarding: slides, Skip stores the flag and goes to login
- Login: required fields, trimmed/lower-cased email, user stored, wrong password / rate limit / no connection messages with the button usable again, Show/Hide, links
- Registration step 1: every field error, E.164 phone, city picker, clean values passed to step 2
- Registration step 2: date format, age 16 boundary, password policy and confirmation, payload, CONFLICT / RATE_LIMITED / other errors, Back
- Verify email: 6 digits required, digits-only input, success → login, error messages, resend with a 60 s cooldown, resend failure
- Forgot password: email validation, same confirmation for any outcome except rate limiting
