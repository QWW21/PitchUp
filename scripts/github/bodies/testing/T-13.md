## Summary

Automated accessibility checks on every web page with axe-core, against WCAG 2.1 A and AA.

## Scope

- Auth pages: login (with and without an error), register (with field errors), forgot password, reset (bad and valid link), verify email, registration confirmed, login on a phone
- Manager dashboard
- Player pages: Discover (list, empty, phone, filters drawer), city dialog, first-visit city prompt, player menu, company page (hours, reviews tab), venue not found, pitch page (desktop, phone, lightbox)
- Fix what the scan finds

- [ ] `e2e/web/a11y.spec.ts` green in CI with no rules disabled
